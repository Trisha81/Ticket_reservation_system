🎫 Ticket Reservation System

A Python-based Ticket Reservation System developed using Data Structures and Algorithms to simulate real-world ticket booking operations. The system enables users to search available tickets, book and cancel reservations, check seat availability, and manage waiting lists efficiently.

The project implements various DSA concepts such as Stack, Queue, Binary Search Tree (BST), Graphs, BFS, DFS, Linear Search, and Binary Search to optimize reservation management and search operations. It demonstrates the practical application of fundamental computer science concepts in solving real-world reservation and booking challenges.
